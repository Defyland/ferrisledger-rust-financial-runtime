# Use Cases

1. Open a tenant-scoped account.
2. Deposit funds with an idempotency key.
3. Request an outgoing Pix transfer and reserve available balance.
4. Execute settlement and reduce booked balance.
5. Create a ledger entry for accounting evidence.
6. Replay an account stream into a current snapshot.
7. Verify append-only event-log checksums during readiness or incident response.
