# Personas

## Platform Engineer

Builds ledger, wallet, Pix, or settlement features and needs a small runtime
that demonstrates event contracts, replay, and Rust ownership boundaries.

## SRE

Responds to failed readiness checks, corrupt event logs, replay drift, or
unexpected command rejections.

## Technical Reviewer

Evaluates whether the codebase demonstrates senior engineering judgment across
domain modeling, observability, security, tests, and trade-offs.
