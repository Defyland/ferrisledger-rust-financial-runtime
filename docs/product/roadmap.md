# Product Roadmap

## Now

- Local append-only event runtime.
- HTTP and CLI adapters.
- Replay, readiness verification, metrics, and tests.

## Next

- PostgreSQL event-store adapter.
- Segment rotation and snapshots.
- Outbox publishing for downstream consumers.
- Scoped API keys.

## Later

- Provider adapters for Pix rails.
- OpenTelemetry trace export.
- Fuzzing and chaos tests for event-log parsing.
- Cryptographic signing for tamper-evident records.
