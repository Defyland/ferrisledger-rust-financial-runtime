## Analysis

The load run stayed well under the configured thresholds of p95 < 750 ms,
p99 < 1200 ms, and error rate < 1%. The max latency outlier is visible in the
summary, but it did not affect the p99 threshold. The observed bottleneck is
still JSONL append and fsync under a single local file. The next optimization
remains a segmented file or PostgreSQL event-store adapter with a persisted
idempotency index.
